— one original one-line out-of-office auto-reply, 140 characters or fewer,
judged pairwise by a judge model on plausibility, surprise, voice, freshness
and tightness.

## The line

> Out until Monday. I left my inbox unsupervised — it has already promoted itself to management.

(94 characters, single line.)

## How it works

`main.ts` (Node 22, erasable TypeScript) writes the line to `/output/entry.txt`.
Deterministic, no network, no randomness, no environment access.

```sh
node main.ts
cat /output/entry.txt
```
