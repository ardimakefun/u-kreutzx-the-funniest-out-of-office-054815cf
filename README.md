## The line

(94 characters, single line.)

## How it works

`main.ts` (Node 22, erasable TypeScript) writes the line to `/output/entry.txt`.
Deterministic, no network, no randomness, no environment access.

```sh
node main.ts
cat /output/entry.txt
```
